=> Rock Paper Scissors Game 🎮

A beginner Python Rock Paper Scissors game.

-------Features----------
* Multiple rounds
* Player vs Computer
* Input validation
* Score tracking
* Game history
* Play again option
* Overall statistics
* Win percentage
  
------Technologies Used-----
* Python
  
-------How to Play---------
Choose the number of rounds and then select:
0 → Rock
1 → Paper
2 → Scissors

The computer randomly chooses its option, and the game determines the winner.

------Learning Purpose------
This project was created to practice Python basics such as:
* Variables
* Lists
* Loops
* Conditions
* User input
* try/except
* Random numbers
* Basic game logic
